# 실제 면접 영상 분석 결과 (M2/M5 실측, 2026-05-24)

슬라이딩 윈도우 모듈을 실제 면접 답변 클립에 **GilJob 실조건(1fps 프레임 + 16kHz 오디오)**으로
돌린 결과. 증거 원본: `.sisyphus/evidence/m2-window-eval.json`, `m5-e2e.json`.

> ⚠️ **이 문서의 한계(먼저 읽을 것)**: 현재 증거에는 클립당 **신호 샘플 1개씩**만 저장돼 있고
> (전체 per-window 타임라인 아님), 저장된 평가 샘플은 둘 다 **window 0 = 자기소개 오프닝**이다.
> 따라서 "신호가 턴/지원자에 따라 *구별되는가*"는 **이 데이터로 판단 불가** — [[OPEN-DECISIONS]] #5의
> 핵심 미검증 항목. 아래는 *모듈이 동작하며 well-formed 신호를 낸다*까지의 결과이고,
> *신호 변별력*은 별도 검증(전체 타임라인 + 대조 클립) 대상이다.

## 무엇을 돌렸나
- 클립: `vid_0001.mp4`(43.5s), `vid_0033.mp4`(50.3s) — 둘 다 영어/한국어 자기소개성 면접 답변.
- 파이프라인: 1fps 프레임을 16s 윈도우로 mp4(`video_url`) + 16kHz PCM을 wav(`audio_url`)로 조립
  → E4B 단일 추론 → per-window 구조화 신호(채널① 비언어 / ② 평가). 집계 없음.

## 산출 신호 (개수·지연)

| 클립 | 길이 | 비언어①(개) | 평가②(개) | 비언어 지연 | 평가 지연 | end-of-turn 확정 |
|---|---|---|---|---|---|---|
| vid_0001 | 43.5s | 15 | 3 | mean 0.47s (0.40–0.51) | mean 2.69s (2.05–3.89) | 2.46s |
| vid_0033 | 50.3s | 17 | 4 | mean 0.47s (0.45–0.51) | mean 1.66–4.65s | 2.13s |

→ **지연은 견고**: 비언어 read 0.47s로 두 클립 일관(backchannel cadence 충분), 확정 ~2.1–2.5s.

## 실제 신호 내용 (저장된 샘플 — 둘 다 window 0 오프닝)

**채널② 평가 (vid_0001, [0,16s])**
- verbal: 논리="논리적 흐름이 자연스럽다" · structure="자기소개 기본 요소를 잘 포함" · specificity="전공·학교를 구체적으로 언급"
- vocal: volume="적절·또렷" · pace="적당·편안" · pauses="자연스러운 곳에서 멈춤" · intonation="안정적·자신감"
- visual: eye_contact="카메라 응시·안정적 시선" · posture="바른 자세·프로페셔널" · expression="차분·자신감" · gesture="특별한 제스처 없음"
- 관찰: "핵심 정보 빠짐없이 전달" / "자신감 있고 안정적" / "발음 명확"

**채널② 평가 (vid_0033, [0,16s])** — 거의 동일 패턴(논리 자연스러움, 적절한 볼륨, 바른 자세, 차분·자신감).

**채널① 비언어 (window 0 근처)**: vid_0001 `engaged` 0.8 "eye contact + posture/smiling" / vid_0033 `confident` 0.8 "eye contact + posture".

## 정직한 해석

1. **됨**: 모듈이 실제 영상에서 well-formed한 한국어 verbal/vocal/visual 평가 + 비언어 상태를
   안정적 지연으로 산출한다. 파이프라인·전송·파싱·스키마가 실제 데이터에서 동작.
2. **아직 모름 (핵심)**: 두 샘플이 모두 *오프닝 자기소개*라 자연히 비슷하다 — 이걸로
   "신호가 획일적"이라 단정하는 것도, "변별력 있다"고 주장하는 것도 **둘 다 과대해석**이다
   (얇은 데이터 일반화 금지). 비언어가 둘 다 `0.8`·긍정 라벨인 점은 *positivity bias 가능성*을
   시사하나 표본 2개로는 미결.
3. **그래서 다음**: ① 전체 per-window 타임라인 저장(턴 내 신호가 *변하는가*), ② 대조 클립
   (긴장/회피/저자신감이 뚜렷한 답변)으로 **변별력 테스트** — 라벨이 상태를 실제 구분하는지.
   이게 통과해야 출력 스키마([[OPEN-DECISIONS]] #5)를 확정할 수 있다.
